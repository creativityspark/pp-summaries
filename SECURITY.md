# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Report them privately to the repository maintainers through GitHub Security Advisories.

Include the affected component, reproduction steps, potential impact, and any suggested mitigation. We will acknowledge the report and coordinate remediation before public disclosure.

## Reference implementation

Summary Studio is a reference implementation. Before production use, review Dataverse security roles, connector permissions, data-loss-prevention policies, environment variables, AI Builder capacity, logging, and regional data-boundary requirements.
